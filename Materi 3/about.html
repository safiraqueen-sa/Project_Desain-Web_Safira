Halo Saya Safira

biasa dipanggil Fira. Saya berasal dari Ponorogo. Saya merupakan lulusan dari SMKN 1 JENANGAN, jurusan RPL. Saat ini, saya sedang menempuh pendidikan di UNS tepatnya di Fakultas Keguruan dan Ilmu Pendidikan Program Studi PTIK. Saya merupakan mahasiswa semester 3.
Saya memilih Program Studi PTIK karena saya ingin melanjutkan studi saya di ranah informatika. Selama menjalani perkuliahan, saya mulai tertarik dengan bidang desain website dan sedang mengembangkan kemampuan dalam membuat tampilan web.
Selain kegiatan akademik, saya juga mengikuti beberapa kegiatan diluar PTIK seperti seni tari dan karawitan serta mengikuti beberapa volunteer untuk lebih dalam mengeksplore hal-hal yang ada di UNS. Dari berbagai kegiatan tersebut, saya mendapatkan pengalaman dalam mengembangkan skill komunikasi, bertanggung jawab dalam menyelesaikan beberapa urusan sekaligus, serta dapat melatih kecepatan dalam berpikir.
